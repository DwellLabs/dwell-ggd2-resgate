# DWËLL RESGATE™ — GGD2
Portal web independente de Mac, SSD e painel, para recuperar arquivos da área privada appDataFolder do Google Drive.
O repositório contém SOMENTE CÓDIGO e NENHUM arquivo criativo, pessoal, vídeo, foto, backup, chave ou token.
- Conta autorizada: dwell.co.music@gmail.com.
- OAuth: drive.appdata e userinfo.email; cliente web público (não é segredo).
- Operações implementadas: somente GET (listagem e download); sem exclusão, upload, gravação ou sincronização.
- Token guardado apenas em memória da aba e revogado ao sair.
- Arquivos grandes exigem Chrome ou Edge para gravar em streaming.
- Este portal não substitui a conta Google: perder a conta pode afetar GGD1 e GGD2.
- Testar acesso e download reais em dispositivo diferente antes da homologação.
- A página em si depende do GitHub Pages. Conservar código e credencial OAuth no projeto Google para reconstrução independente.
